# Tide Coffee — website

The storefront for Tide Coffee, a small-batch roaster: what we roast, what it
costs, and how cafés order wholesale.

A plain static site, no build step. Open `index.html`, or serve the folder:

```sh
python3 -m http.server 8000
```

- `index.html`: the home page and the shop
- `data/products.json`: every bag we sell and its price (the shop reads it)
- `styles.css`: the look

> A demo company for the [DeckHands video guides](https://mydeckhands.com/guides).
